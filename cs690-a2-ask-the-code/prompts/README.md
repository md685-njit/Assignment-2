# prompts/

Save here the prompts you gave AI tools while doing this assignment, one file per
ledger entry, for example `split-01.md` or `five-part-v2.md`. Paste the prompts
verbatim. For a long session, a summary of the session is acceptable.

The `prompts:` field of each LEDGER.md entry names the file here that holds its prompts.

This folder is for prompts you typed to a tool. The prompt your program builds lives
in `askcode/prompt.py`, and every reply the AI gave your program is saved in `ai_replies/`.
